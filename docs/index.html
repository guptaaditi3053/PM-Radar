PM Radar

Fresh LinkedIn posts on product management interviews and skills, with a short summary and a link for each.

+ Fetch new posts Starts a new LinkedIn search

A search takes 1 to 3 minutes. A full run uses about 22 of your 1,000 free monthly searches. A custom search uses 1 or 2.

One-time setup: connect this button to your GitHub
  1. On GitHub, click your profile picture, then Settings, then Developer settings (bottom of the left menu), then Personal access tokens, then Fine-grained tokens, then Generate new token.
  2. Name it pm-radar-button. Set the expiration to 90 days.
  3. Under Repository access, choose Only select repositories and pick PM-Radar.
  4. Under Permissions, then Repository permissions, set Actions to Read and write. Leave everything else alone.
  5. Click Generate token, copy it, and paste it below. It is stored only in this browser, never in your repository. Don't share it.

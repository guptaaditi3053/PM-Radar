Run a new search

A search takes about 1–3 minutes. Each full run uses ~22 of your free monthly searches; a custom search uses 1–2.

One-time setup: connect this button to your GitHub
  1. On GitHub, click your profile picture → Settings → Developer settings (bottom of the left menu) → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it pm-radar-button. Expiration: 90 days.
  3. Repository access → Only select repositories → choose PM-Radar.
  4. Permissions → Repository permissions → set Actions to Read and write. Leave everything else alone.
  5. Click Generate token, copy it, and paste it below. It is stored only in this browser, never in your repository. Don't share it.
